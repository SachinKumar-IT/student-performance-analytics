# Student Performance Analytics System

## Overview
The Student Performance Analytics System is a Python-based mini-project that analyzes student marks and attendance using NumPy and Pandas.

## Objectives
- Calculate total and average marks.
- Assign grades based on average marks.
- Evaluate pass/fail results using marks and attendance.
- Perform subject-wise performance analysis.
- Calculate class statistics and identify the top three academic performers.

## Technologies Used
- Python
- NumPy
- Pandas
- CSV

## Project Files
- `main.py` — Main program that runs the analysis.
- `functions.py` — Reusable functions for calculations and evaluation.
- `students.csv` — Dataset containing 20 student records.
- `Project_Documentation.pdf` — Project documentation.

## Features
- Student data loading and display.
- Total marks and average calculation.
- Grade assignment.
- Pass/fail evaluation.
- Subject-wise average, highest, and lowest marks.
- Overall class statistics.
- Top three academic performers.

## How to Run
1. Install Python on your computer.
2. Install the required libraries:

   ```bash
   pip install pandas numpy
   ```

3. Keep `main.py`, `functions.py`, and `students.csv` in the same folder.
4. Open a terminal in that folder.
5. Run the program:

   ```bash
   python main.py
   ```

## Output
The program displays student performance, grades, results, class statistics, subject-wise analysis, and the top three academic performers in the terminal.
